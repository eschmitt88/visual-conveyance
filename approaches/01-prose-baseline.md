# Approach 01 — prose baseline (control)

Communicate the material as a single well-written document page. This is
deliberately the no-graphics control condition.

## Method

- Structure: title → one-paragraph executive summary (bolded key
  sentence) → sections with clear headings → short conclusion. Inverted
  pyramid: most important first.
- Typography does the visual work: heading scale, bold lead-ins, short
  paragraphs (≤4 sentences), generous line-height and margins, a max
  text width around 70ch.
- Lists and tables ARE allowed (they are text), and so are blockquote
  callouts for caveats. Use them where prose alone would bury structure.
- Aim for the length the material needs — typically 800–1500 words.

## Hard constraints (keeps the cell distinct)

- NO diagrams, NO SVG graphics, NO charts, NO icons, NO images.
- No JavaScript beyond nothing — this page needs none.
- Color only for text emphasis and callout backgrounds, not for
  encoding data.

## Glance zone

The executive summary and, if room allows, the first section heading
must sit above the fold. The bolded key sentence carries the takeaway.
