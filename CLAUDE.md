# Project: visual-conveyance

Short orientation only. User-level `~/.claude/CLAUDE.md` holds the durable
principles; this file refines them for this project.

## What this project is about

Find the best way for an AI agent to communicate complex information to a
human **visually** — diagramming languages, static HTML, infographics,
interactive pages. Phase 1: static GitHub-Pages presentations, generated by
a fixed set of *approaches* (prompt specs in `approaches/`) applied to a
fixed set of *test cases* (`testcases/`), scored by AI evaluators and then
ranked by the human. See `docs/decisions/0001-experiment-design.md`.

## Project-specific facts

- Primary artifacts: static HTML under `docs/presentations/<testcase>/<approach>/`.
- `approaches/` = method prompt specs; `testcases/` = fixed source material
  with `key_facts.md` ground truth for accuracy scoring. Both are versioned;
  changing either invalidates cross-run comparisons (record an ADR).
- AI evals live inside each experiment (`results/evals/`); aggregate scores
  in `metrics.json`. Every presentation carries `human_evaluated: true|false`
  in `docs/presentations/manifest.json`.
- Environment: managed by `uv`; run `make env` to sync.
