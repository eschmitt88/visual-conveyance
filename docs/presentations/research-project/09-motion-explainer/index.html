murmur — do near-free, reverb-flavoured audio augmentations lift a small bird-call classifier?

Six experiments, March–June 2026, on 6,200 clips across 34 long-tailed species: the bet is that physically-plausible augmentation beats spending the same budget on a bigger backbone. Verdict below: partially supported.

  1. Baseline (exp-01): small CNN, no augmentation — validation macro-F1 0.612. Tail classes carry almost all the error.
  2. Light impulse-response reverb (exp-02): 0.641, +0.029 — the first clear win; gain skews to common/mid tiers.
  3. Pitch/time stretch (exp-03): 0.589, below baseline — warping smears the spectral cues rare classes depend on.
  4. Noise mixing (exp-04): 0.643, only +0.002 over reverb alone — a null result, inside ±0.006 seed noise.
  5. The stack (exp-05): reverb + noise mix + SpecAugment + partial balanced sampler — 0.671, +0.059, current best.
  6. Heavy reverb (exp-06): 0.663, below best — helps common classes further, blurs short rare-class calls.
  7. Per-species: head gains +0.06–0.07, Wood Thrush +0.03, Kirtland's Warbler −0.01 — the lift barely reaches the tail.
  8. Verdict: partially supported. Next: class-conditional augmentation — apply each transform only where it helps; protect the tail.
