The four rules

Only store/writer.py writes the DB.
Extractor is pure — bytes in, Article out.
FTS index updated by triggers only.
store/ imports nothing; nothing imports api/ or cli/.
The 3,280-line web/ frontend has zero tests. reader.js (920 LOC) pins highlights to character offsets in rendered HTML — template changes silently corrupt them; 3 of the last 10 user-reported bugs.
