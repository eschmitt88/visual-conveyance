meridian — the shape of the codebase

A self-hosted read-later / RSS service: a one-way ingest pipeline writes into a single SQLite file, which a small HTTP API, a vanilla-JS web reader, and a CLI read back out. One process runs the API, one runs the workers — no external broker, cache, or database server.
